# Анализ конфиденциальных данных компании "Медикаменте"

## Введение

В данном документе проводится анализ конфиденциальных данных, которые обрабатываются в компании "Медикаменте", но не учтены должным образом во внутренних системах безопасности.

## Выявленные конфиденциальные данные

### 1. Персональные данные пациентов (PII - Personally Identifiable Information)

#### Базовые персональные данные:
- **ФИО** - полное имя пациента
- **Дата рождения** - позволяет идентифицировать личность
- **Телефон** - контактная информация
- **Электронная почта** - контактная информация

#### Расширенные персональные данные:
- **Адрес прописки** - место постоянного проживания
- **Место работы или учёбы** - информация о профессиональной деятельности
- **Хронические заболевания** - медицинская информация, относится к категории особо чувствительных данных

### 2. Медицинские данные (PHI - Protected Health Information)

#### Медицинские карты:
- История болезни пациента
- Диагнозы и заключения врачей
- Результаты осмотров
- Назначенные препараты и процедуры
- История обращений в клинику

#### Результаты анализов:
- Лабораторные исследования
- Результаты диагностических процедур
- Медицинские изображения (рентген, УЗИ и т.д.)

### 3. Финансовые данные

#### Платежная информация:
- Данные о платежах пациентов
- История оплаты услуг
- Информация о договорах и контрактах
- Данные ККМ (контрольно-кассовых машин)

#### Бухгалтерские данные:
- Финансовые операции
- Зарплатные ведомости сотрудников
- Налоговая отчетность

### 4. Данные сотрудников

#### Кадровые данные:
- Персональные данные сотрудников
- Зарплатная информация
- Данные о трудовых договорах

## Данные, не учтенные в системах безопасности

### Проблемные категории данных:

1. **Медицинские карты в формате сканов (JPG, PDF)**
   - Хранятся на общем диске без разграничения доступа
   - Нет контроля, кто и когда просматривал карты
   - Нет шифрования при хранении
   - Нет защиты от копирования

2. **Excel-файлы с журналами приёма**
   - Содержат персональные данные пациентов
   - Доступны всем сотрудникам с доступом к общему диску
   - Нет версионирования и контроля изменений
   - Нет резервного копирования с шифрованием

3. **Данные в 1С:Бухгалтерия**
   - Работает в файловом режиме (не клиент-сервер)
   - Нет разграничения доступа к конфиденциальным данным
   - Финансовая информация доступна всем пользователям 1С
   - Нет аудита доступа к данным

4. **Данные в 1С:Торговля и склад**
   - Информация о закупках и ТМЦ может содержать данные о поставщиках
   - Нет контроля доступа к финансовой информации

5. **Данные в Exchange Mail Server**
   - Переписка может содержать персональные данные пациентов
   - Нет шифрования почтовых сообщений
   - Нет контроля пересылки конфиденциальной информации

6. **Данные в Active Directory**
   - Учетные записи сотрудников
   - Пароли и права доступа
   - Нет многофакторной аутентификации

7. **Данные на файловом сервере**
   - Все файлы доступны через общий доступ
   - Нет разграничения прав доступа по папкам
   - Нет шифрования файлов на диске

8. **Данные в процессе передачи между системами**
   - Интеграция ККМ с 1С через OLE и TCP/IP без шифрования
   - Нет контроля передаваемых данных
   - Нет логирования передач

## Классификация данных по уровню конфиденциальности

### Уровень 1 - Критически конфиденциальные (требуют максимальной защиты):
- Хронические заболевания
- Результаты анализов
- Медицинские диагнозы
- Полные медицинские карты

### Уровень 2 - Высококонфиденциальные (требуют строгой защиты):
- ФИО + дата рождения
- Адрес прописки
- Финансовые данные о платежах
- Данные о месте работы/учёбы

### Уровень 3 - Конфиденциальные (требуют базовой защиты):
- Телефон
- Электронная почта
- Данные о записях на приём
- Общая информация о пациентах

## Риски, связанные с неучтенными данными

1. **Риск утечки данных** - отсутствие контроля доступа позволяет любому сотруднику скопировать конфиденциальные данные
2. **Риск несанкционированного доступа** - нет разграничения прав, все данные доступны всем
3. **Риск потери данных** - отсутствие резервного копирования и версионирования
4. **Риск нарушения законодательства** - несоответствие требованиям 152-ФЗ "О персональных данных"
5. **Риск репутационных потерь** - утечка медицинских данных может привести к потере доверия клиентов
6. **Риск финансовых потерь** - штрафы за нарушение законодательства о защите персональных данных

## Выводы

Компания "Медикаменте" обрабатывает значительный объем конфиденциальных данных, которые в настоящее время не защищены должным образом. Основные проблемы:

- Отсутствие классификации данных по уровню конфиденциальности
- Отсутствие разграничения доступа к данным
- Отсутствие шифрования при хранении и передаче
- Отсутствие аудита доступа к данным
- Хранение данных в незащищенных форматах на общих ресурсах

Необходимо срочно внедрить меры по защите данных на всех уровнях обработки информации.
