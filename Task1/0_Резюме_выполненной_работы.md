Данный документ является навигационным и содержит краткое описание выполненной работы по анализу безопасности данных в компании "Медикаменте" в рамках Задания 1.

Работа выполнена в соответствии с требованиями задания и включает следующие документы:

### 1. Анализ конфиденциальных данных
**Файл:** `1_Анализ_конфиденциальных_данных.md`

**Содержание:**

### 5. Доработанные диаграммы потоков данных (To-Be)
**Файл:** `5_Доработанные_диаграммы_потоков_данных.md`

**Содержание:**
- Доработанные диаграммы потоков данных с указанием мер защиты на каждом этапе
- 6 основных процессов с детализацией мер защиты
- Дополнительная диаграмма процесса передачи данных в BI/ML/AI системы
- Сводная таблица мер защиты по процессам

**Меры защиты, отображённые на диаграммах:**
- **[ENC]** - Шифрование данных (AES-256)
- **[AUTH]** - Аутентификация (MFA, API Keys)
- **[AUTHZ]** - Авторизация (RBAC, ABAC)
- **[AUDIT]** - Аудит и логирование
- **[TAG]** - Тегирование данных
- **[MASK]** - Маскирование данных
- **[ANON]** - Обезличивание данных
- **[DLP]** - Data Loss Prevention
- **[TLS]** - Защищённое соединение

**Основные улучшения:**
- Все данные шифруются при хранении и передаче
- Внедрён многоуровневый контроль доступа (MFA + RBAC)
- Все операции логируются и аудируются
- Данные автоматически тегируются при обработке
- Чувствительные данные маскируются при отображении
- Данные обезличиваются перед передачей в BI/ML/AI системы

## Ключевые результаты анализа

### Выявленные конфиденциальные данные

1. **Персональные данные пациентов (PII):**
   - ФИО, дата рождения, телефон, email
   - Адрес прописки, место работы/учёбы
   - Хронические заболевания

2. **Медицинские данные (PHI):**
   - Медицинские карты
   - Результаты анализов
   - Диагнозы и заключения врачей

3. **Финансовые данные:**
   - Данные о платежах пациентов
   - Бухгалтерская информация
   - Зарплатные данные сотрудников

4. **Кадровые данные:**
   - Персональные данные сотрудников
   - Данные о трудовых договорах

### Основные проблемы безопасности

1. **Критические:**
   - Медицинские карты на общем диске без защиты
   - Отсутствие разграничения доступа
   - Отсутствие шифрования данных
   - Отсутствие аудита операций

2. **Высокие:**
   - Дублирование данных в разных системах
   - Небезопасные протоколы передачи
   - Отсутствие резервного копирования
   - Отсутствие политики удаления данных

3. **Средние:**
   - Отсутствие классификации данных
   - Отсутствие тегирования данных
   - Отсутствие многофакторной аутентификации
   - Отсутствие системы мониторинга

### Рекомендуемые меры защиты

1. **Шифрование:**
   - AES-256 при хранении
   - TLS 1.3 при передаче
   - TDE для баз данных

2. **Контроль доступа:**
   - Многофакторная аутентификация (MFA)
   - Role-Based Access Control (RBAC)
   - Attribute-Based Access Control (ABAC)

3. **Мониторинг и аудит:**
   - Централизованное логирование (ELK Stack)
   - Детальный аудит всех операций
   - Системы обнаружения аномалий (SIEM)

4. **Управление данными:**
   - Система тегирования данных
   - Data Loss Prevention (DLP)
   - Data Lineage для отслеживания потоков

5. **Обработка данных:**
   - Маскирование чувствительных данных
   - Обезличивание для аналитики
   - Автоматическое удаление по истечении срока
