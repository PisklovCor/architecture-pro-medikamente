# Диаграммы потоков данных (Data Flow Diagrams)

## Введение

В данном документе представлены диаграммы потоков данных для основных бизнес-процессов компании "Медикаменте". Каждая диаграмма описывает, как данные перемещаются между системами и какие операции над ними выполняются.

## Обозначения

- **Прямоугольник** - внешняя сущность (пациент, сотрудник, внешняя система)
- **Круг** - процесс обработки данных
- **Параллельные линии** - хранилище данных
- **Стрелка** - поток данных с указанием типа данных

## Диаграмма 1: Процесс записи пациента на приём

### Контекстная диаграмма (DFD Level 0)

```
[Пациент] --(ФИО, телефон, дата рождения, причина обращения)--> [Процесс записи на приём]
[Процесс записи на приём] --(Данные о записи)--> [Журнал записей Excel]
[Процесс записи на приём] --(Персональные данные)--> [База данных пациентов Excel]
[Сотрудник ресепшена] <--(Информация о записи)-- [Процесс записи на приём]
[Сотрудник ресепшена] --(Ввод данных)--> [Процесс записи на приём]
```

### Детальная диаграмма (DFD Level 1)

```
Процесс: Запись пациента на приём

1.1 [Сотрудник ресепшена] --(Получение данных от пациента)--> [Процесс 1.1: Приём данных]
1.2 [Процесс 1.1] --(Проверка данных)--> [Процесс 1.2: Валидация данных]
1.3 [Процесс 1.2] --(Валидные данные)--> [Процесс 1.3: Сохранение в Excel]
1.4 [Процесс 1.3] --> [D1: Журнал записей Excel]
1.5 [Процесс 1.3] --> [D2: База пациентов Excel]
1.6 [Процесс 1.3] --(Подтверждение записи)--> [Сотрудник ресепшена]
1.7 [Процесс 1.3] --(Уведомление)--> [Пациент]

Хранилища данных:
D1: Журнал записей Excel (на общем диске)
D2: База пациентов Excel (на общем диске)
```

### Описание операций:

1. **Приём данных** - сотрудник ресепшена получает от пациента персональные данные и информацию о желаемой записи
2. **Валидация данных** - проверка корректности введенных данных (формат телефона, даты и т.д.)
3. **Сохранение в Excel** - запись данных в соответствующие Excel-файлы на общем диске

## Диаграмма 2: Процесс приёма пациента и ведения медицинской карты

### Контекстная диаграмма (DFD Level 0)

```
[Пациент] --(Медицинские данные)--> [Процесс приёма пациента]
[Медицинский специалист] <--(Данные пациента)-- [Процесс приёма пациента]
[Медицинский специалист] --(Диагноз, назначения)--> [Процесс приёма пациента]
[Процесс приёма пациента] --(Медицинская карта)--> [Хранилище медицинских карт]
[Процесс приёма пациента] --(Данные о приёме)--> [Журнал приёмов Excel]
```

### Детальная диаграмма (DFD Level 1)

```
Процесс: Приём пациента и ведение медицинской карты

2.1 [Медицинский специалист] --(Запрос данных пациента)--> [Процесс 2.1: Получение данных пациента]
2.2 [Процесс 2.1] --> [D2: База пациентов Excel]
2.3 [D2: База пациентов Excel] --(Данные пациента)--> [Процесс 2.1]
2.4 [Процесс 2.1] --(Данные пациента)--> [Медицинский специалист]
2.5 [Медицинский специалист] --(Результаты осмотра, диагноз)--> [Процесс 2.2: Оформление медицинской карты]
2.6 [Процесс 2.2] --> [D3: Медицинские карты (сканы JPG/PDF)]
2.7 [Процесс 2.2] --> [D1: Журнал приёмов Excel]
2.8 [Процесс 2.2] --(Информация о приёме)--> [Медицинский специалист]

Хранилища данных:
D2: База пациентов Excel
D3: Медицинские карты (сканы на общем диске)
D1: Журнал приёмов Excel
```

### Описание операций:

1. **Получение данных пациента** - медицинский специалист запрашивает данные пациента из базы Excel
2. **Оформление медицинской карты** - специалист заполняет медицинскую карту, которая сохраняется как скан (JPG/PDF) на общем диске

## Диаграмма 3: Процесс обработки анализов

### Контекстная диаграмма (DFD Level 0)

```
[Лаборатория] --(Результаты анализов)--> [Процесс обработки анализов]
[Медицинский специалист] <--(Результаты анализов)-- [Процесс обработки анализов]
[Процесс обработки анализов] --(Результаты)--> [Хранилище анализов]
[Пациент] <--(Результаты анализов)-- [Процесс обработки анализов]
```

### Детальная диаграмма (DFD Level 1)

```
Процесс: Обработка анализов

3.1 [Лаборатория] --(Результаты анализов)--> [Процесс 3.1: Получение результатов]
3.2 [Процесс 3.1] --(Сохранение)--> [D4: Учёт анализов Excel]
3.3 [Процесс 3.1] --(Сохранение сканов)--> [D5: Сканы анализов (JPG/PDF)]
3.4 [Процесс 3.2: Уведомление специалиста] --> [D4: Учёт анализов Excel]
3.5 [Процесс 3.2] --(Уведомление)--> [Медицинский специалист]
3.6 [Медицинский специалист] --(Запрос результатов)--> [Процесс 3.3: Получение результатов]
3.7 [Процесс 3.3] --> [D4: Учёт анализов Excel]
3.8 [Процесс 3.3] --> [D5: Сканы анализов]
3.9 [Процесс 3.3] --(Результаты)--> [Медицинский специалист]
3.10 [Медицинский специалист] --(Передача пациенту)--> [Процесс 3.4: Выдача результатов]
3.11 [Процесс 3.4] --(Результаты)--> [Пациент]

Хранилища данных:
D4: Учёт анализов Excel (на общем диске)
D5: Сканы анализов (JPG/PDF на общем диске)
```

### Описание операций:

1. **Получение результатов** - получение результатов анализов от лаборатории и сохранение в Excel и виде сканов
2. **Уведомление специалиста** - уведомление медицинского специалиста о готовности результатов
3. **Получение результатов** - запрос и получение результатов анализов специалистом
4. **Выдача результатов** - передача результатов анализов пациенту

## Диаграмма 4: Процесс приёма платежей

### Контекстная диаграмма (DFD Level 0)

```
[Пациент] --(Оплата услуг)--> [Процесс приёма платежей]
[Кассир] <--(Данные об оплате)-- [Процесс приёма платежей]
[Кассир] --(Ввод данных)--> [Процесс приёма платежей]
[Процесс приёма платежей] <--> [ККМ]
[Процесс приёма платежей] --(Данные о платеже)--> [1С:Бухгалтерия]
[Процесс приёма платежей] --(Данные о платеже)--> [Учёт платежей Excel]
```

### Детальная диаграмма (DFD Level 1)

```
Процесс: Приём платежей

4.1 [Кассир] --(Данные об услуге и пациенте)--> [Процесс 4.1: Формирование чека]
4.2 [Процесс 4.1] <--(Данные чека)--> [ККМ]
4.3 [ККМ] --(Чек)--> [Процесс 4.1]
4.4 [Процесс 4.1] --(Данные о платеже)--> [Процесс 4.2: Сохранение в Excel]
4.5 [Процесс 4.2] --> [D6: Учёт платежей Excel]
4.6 [Процесс 4.2] --(Данные о платеже)--> [Процесс 4.3: Интеграция с 1С]
4.7 [Процесс 4.3] <--(OLE, TCP/IP)--> [1С:Бухгалтерия]
4.8 [Процесс 4.3] --> [D7: 1С:Бухгалтерия (файловый режим)]
4.9 [Процесс 4.1] --(Чек)--> [Пациент]

Хранилища данных:
D6: Учёт платежей Excel (на общем диске)
D7: 1С:Бухгалтерия (файловый режим на сервере)
```

### Описание операций:

1. **Формирование чека** - кассир формирует чек через ККМ
2. **Сохранение в Excel** - данные о платеже сохраняются в Excel для двойного учёта
3. **Интеграция с 1С** - данные передаются в 1С:Бухгалтерия через OLE и TCP/IP

## Диаграмма 5: Процесс бухгалтерского учёта

### Контекстная диаграмма (DFD Level 0)

```
[Бухгалтер] <--(Финансовые данные)-- [Процесс бухгалтерского учёта]
[Бухгалтер] --(Ввод данных)--> [Процесс бухгалтерского учёта]
[Процесс бухгалтерского учёта] <--> [1С:Бухгалтерия]
[Процесс бухгалтерского учёта] --(Отчёты)--> [Налоговые органы]
[Процесс бухгалтерского учёта] --(Данные о зарплате)--> [Сотрудники]
```

### Детальная диаграмма (DFD Level 1)

```
Процесс: Бухгалтерский учёт

5.1 [Бухгалтер] --(Данные о платежах)--> [Процесс 5.1: Обработка платежей]
5.2 [Процесс 5.1] --> [D7: 1С:Бухгалтерия]
5.3 [Бухгалтер] --(Кадровые данные)--> [Процесс 5.2: Учёт кадров]
5.4 [Процесс 5.2] --> [D7: 1С:Бухгалтерия]
5.5 [Процесс 5.2] --(Расчёт зарплаты)--> [Процесс 5.3: Начисление зарплаты]
5.6 [Процесс 5.3] --> [D7: 1С:Бухгалтерия]
5.7 [Процесс 5.3] --(Ведомость)--> [Сотрудники]
5.8 [Бухгалтер] --(Формирование отчётов)--> [Процесс 5.4: Подготовка отчётов]
5.9 [Процесс 5.4] --> [D7: 1С:Бухгалтерия]
5.10 [Процесс 5.4] --(Налоговые отчёты)--> [Налоговые органы]

Хранилища данных:
D7: 1С:Бухгалтерия (файловый режим)
```

### Описание операций:

1. **Обработка платежей** - обработка данных о платежах от пациентов
2. **Учёт кадров** - ведение кадрового учёта сотрудников
3. **Начисление зарплаты** - расчёт и начисление заработной платы
4. **Подготовка отчётов** - формирование отчётов для налоговых органов

## Диаграмма 6: Процесс учёта товарно-материальных ценностей

### Контекстная диаграмма (DFD Level 0)

```
[Сотрудник склада] <--(Данные о ТМЦ)-- [Процесс учёта ТМЦ]
[Сотрудник склада] --(Ввод данных)--> [Процесс учёта ТМЦ]
[Процесс учёта ТМЦ] <--> [1С:Торговля и склад]
[Процесс учёта ТМЦ] <--> [1С:Бухгалтерия]
```

### Детальная диаграмма (DFD Level 1)

```
Процесс: Учёт товарно-материальных ценностей

6.1 [Сотрудник склада] --(Данные о поступлении)--> [Процесс 6.1: Учёт поступления]
6.2 [Процесс 6.1] --> [D8: 1С:Торговля и склад]
6.3 [Сотрудник склада] --(Данные о расходе)--> [Процесс 6.2: Учёт расхода]
6.4 [Процесс 6.2] --> [D8: 1С:Торговля и склад]
6.5 [Процесс 6.3: Интеграция с бухгалтерией] <--> [D8: 1С:Торговля и склад]
6.6 [Процесс 6.3] <--> [D7: 1С:Бухгалтерия]
6.7 [Сотрудник склада] --(Запрос данных)--> [Процесс 6.4: Получение отчётов]
6.8 [Процесс 6.4] --> [D8: 1С:Торговля и склад]
6.9 [Процесс 6.4] --(Отчёты)--> [Сотрудник склада]

Хранилища данных:
D8: 1С:Торговля и склад (файловый режим)
D7: 1С:Бухгалтерия
```

### Описание операций:

1. **Учёт поступления** - регистрация поступления товарно-материальных ценностей
2. **Учёт расхода** - регистрация расхода ТМЦ
3. **Интеграция с бухгалтерией** - синхронизация данных между 1С:Торговля и склад и 1С:Бухгалтерия
4. **Получение отчётов** - формирование отчётов о наличии и движении ТМЦ

## Общие проблемы потоков данных

1. **Отсутствие шифрования** - все данные передаются и хранятся в открытом виде
2. **Отсутствие контроля доступа** - нет разграничения прав доступа к данным
3. **Отсутствие аудита** - нет логирования операций с данными
4. **Дублирование данных** - одни и те же данные хранятся в разных местах (Excel и 1С)
5. **Небезопасные протоколы** - использование OLE и незащищённого TCP/IP для интеграций
6. **Хранение на общем диске** - все файлы доступны всем пользователям сети
