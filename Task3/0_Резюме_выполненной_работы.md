## Ключевые выводы

### Классификация данных

Данные компании "Медикаменте" классифицированы по следующим критериям:

- **По состоянию:** at rest (хранение), in transit (передача), in use (обработка)
- **По чувствительности:** 4 уровня от TOP_SECRET (медицинские диагнозы) до INTERNAL (общая статистика)
- **По профилю риска:** высокий, средний, низкий
- **По типу обработки:** операционные, аналитические, архивные
- **По юридическим требованиям:** 152-ФЗ, врачебная тайна, PCI DSS

### Инструменты защиты

**При хранении (at rest):**
- TDE для PostgreSQL - прозрачное шифрование баз данных
- BitLocker - шифрование дисков
- HashiCorp Vault - управление ключами
- EFS - шифрование файлов

**При передаче (in transit):**
- TLS 1.3 - для всех веб-соединений
- VPN (WireGuard) - для удалённого доступа
- API Gateway (Kong) - защита API
- mTLS - для межсервисной коммуникации

### Автоматизированный контроль

- DLP-системы для предотвращения утечек
- Мониторинг доступа к базам данных, файлам, API
- ML-модели для обнаружения аномалий
- Автоматическое управление жизненным циклом данных
- Автоматическая проверка соответствия требованиям

### Реестр средств

Подготовлен реестр из 30+ средств защиты, включая:
- Бесплатные открытые решения (PostgreSQL, HashiCorp Vault, ELK Stack, WireGuard)
- Коммерческие решения (Microsoft Purview DLP, Duo Security)
- Аппаратное обеспечение (серверы, TPM, HSM)
