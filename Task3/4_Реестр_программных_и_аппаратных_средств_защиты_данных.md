# Реестр программных и аппаратных средств для защиты данных

## Введение

В данном документе представлен реестр всех программных и аппаратных средств, необходимых для защиты данных в компании "Медикаменте". Реестр включает описание каждого средства, его назначение, технические характеристики, стоимость (где применимо) и приоритет внедрения.

---

## Категория 1: Шифрование данных при хранении (Encryption at Rest)

### 1.1. Средства шифрования баз данных

#### PostgreSQL с расширением pgcrypto
- **Тип:** Программное обеспечение (открытое)
- **Назначение:** Шифрование данных в базе данных PostgreSQL
- **Функциональность:**
  - Прозрачное шифрование данных (TDE)
  - Шифрование отдельных полей (column-level encryption)
  - Управление ключами
- **Технические требования:**
  - PostgreSQL 12 или выше
  - Расширение pgcrypto
  - Интеграция с системой управления ключами
- **Стоимость:** Бесплатно (открытое ПО)
- **Приоритет внедрения:** Критический (Фаза 1)
- **Альтернативы:** Oracle TDE, SQL Server TDE (платные)

#### HashiCorp Vault
- **Тип:** Программное обеспечение (открытое, коммерческая поддержка опциональна)
- **Назначение:** Управление ключами шифрования и секретами
- **Функциональность:**
  - Хранение и управление криптографическими ключами
  - Ротация ключей
  - Хранение секретов (пароли, API-ключи)
  - Управление сертификатами (PKI)
  - Аудит доступа к ключам
- **Технические требования:**
  - Сервер с минимум 4 CPU, 8 GB RAM
  - High Availability конфигурация (рекомендуется)
  - Интеграция с Active Directory
- **Стоимость:** 
  - Community Edition: Бесплатно
  - Enterprise Edition: от $125/узел/месяц (при необходимости поддержки)
- **Приоритет внедрения:** Критический (Фаза 1)
- **Альтернативы:** AWS KMS, Azure Key Vault, Thales CipherTrust (платные облачные/коммерческие решения)

### 1.2. Средства шифрования файловых систем

#### BitLocker Drive Encryption
- **Тип:** Программное обеспечение (встроено в Windows Server)
- **Назначение:** Шифрование дисков на серверах Windows Server 2022
- **Функциональность:**
  - Полное шифрование диска (FDE)
  - Прозрачное для пользователей и приложений
  - Защита ключей через TPM
  - Централизованное управление через Active Directory
- **Технические требования:**
  - Windows Server 2022
  - TPM 2.0 (рекомендуется) или пароль для защиты ключа
  - Active Directory для централизованного управления
- **Стоимость:** Включено в лицензию Windows Server
- **Приоритет внедрения:** Критический (Фаза 1)
- **Альтернативы:** VeraCrypt (бесплатно, кроссплатформенно), LUKS (Linux)

#### Encrypting File System (EFS)
- **Тип:** Программное обеспечение (встроено в Windows Server)
- **Назначение:** Шифрование отдельных файлов и папок
- **Функциональность:**
  - Шифрование на уровне файловой системы NTFS
  - Шифрование отдельных файлов и папок
  - Управление через сертификаты пользователей
- **Технические требования:**
  - Windows Server с NTFS
  - Сертификаты пользователей (через Active Directory Certificate Services)
- **Стоимость:** Включено в лицензию Windows Server
- **Приоритет внедрения:** Средний (Фаза 3)
- **Альтернативы:** VeraCrypt для отдельных файлов

#### VeraCrypt (для резервных копий и Linux серверов)
- **Тип:** Программное обеспечение (открытое, бесплатное)
- **Назначение:** Шифрование резервных копий, файлов, дисков (кроссплатформенное решение)
- **Функциональность:**
  - Создание зашифрованных контейнеров
  - Шифрование разделов диска
  - Шифрование резервных копий
- **Технические требования:**
  - Windows, Linux, macOS
  - Минимальные требования к ресурсам
- **Стоимость:** Бесплатно
- **Приоритет внедрения:** Высокий (Фаза 2) - для резервных копий
- **Альтернативы:** BitLocker (Windows), LUKS (Linux)

### 1.3. Аппаратные средства для шифрования

#### TPM (Trusted Platform Module) 2.0
- **Тип:** Аппаратное обеспечение
- **Назначение:** Защита ключей шифрования на аппаратном уровне
- **Функциональность:**
  - Хранение ключей шифрования в защищённом чипе
  - Защита от извлечения ключей
  - Аппаратная генерация случайных чисел
- **Технические требования:**
  - TPM 2.0 чип на материнской плате серверов
  - Поддержка в BIOS/UEFI
- **Стоимость:** Обычно входит в стоимость серверов (проверить при закупке)
- **Приоритет внедрения:** Критический (Фаза 1) - должен быть на всех серверах
- **Альтернативы:** HSM (Hardware Security Module) - для более высоких требований

#### HSM (Hardware Security Module) - опционально
- **Тип:** Аппаратное обеспечение (для высоких требований)
- **Назначение:** Аппаратное управление ключами для критичных систем
- **Функциональность:**
  - Аппаратное хранение и управление ключами
  - Высокая производительность криптографических операций
  - Соответствие FIPS 140-2 Level 3/4
- **Технические требования:**
  - Отдельное устройство или PCI-карта
  - Интеграция с приложениями через PKCS#11 или другие интерфейсы
- **Стоимость:** От $5,000 до $50,000+ (в зависимости от модели)
- **Приоритет внедрения:** Низкий (для будущего, если потребуется соответствие строгим стандартам)
- **Производители:** Thales, Utimaco, SafeNet

## Категория 2: Шифрование данных при передаче (Encryption in Transit)

### 2.1. Средства TLS/SSL

#### Let's Encrypt (для публичных сервисов)
- **Тип:** Сервис (бесплатный)
- **Назначение:** SSL/TLS сертификаты для публичных веб-сайтов
- **Функциональность:**
  - Бесплатные SSL/TLS сертификаты
  - Автоматическое обновление сертификатов
  - Поддержка wildcard сертификатов
- **Технические требования:**
  - Веб-сервер с поддержкой ACME протокола
  - Публичный домен
- **Стоимость:** Бесплатно
- **Приоритет внедрения:** Критический (Фаза 1)
- **Альтернативы:** Коммерческие SSL-сертификаты (DigiCert, GlobalSign) - от $100/год

#### Внутренний Certificate Authority (CA)
- **Тип:** Программное обеспечение
- **Назначение:** Выдача SSL/TLS сертификатов для внутренних систем
- **Функциональность:**
  - Создание собственного CA
  - Выдача сертификатов для внутренних сервисов
  - Управление жизненным циклом сертификатов
- **Технические решения:**
  - **HashiCorp Vault PKI** - встроенная функциональность PKI в Vault
  - **Active Directory Certificate Services** - для Windows-окружения
  - **OpenSSL + собственные скрипты** - для кастомного решения
- **Стоимость:** Бесплатно (используя HashiCorp Vault или AD CS)
- **Приоритет внедрения:** Высокий (Фаза 2)
- **Альтернативы:** Коммерческие PKI решения

### 2.2. Средства VPN

#### WireGuard
- **Тип:** Программное обеспечение (открытое)
- **Назначение:** VPN для удалённого доступа и межсерверного взаимодействия
- **Функциональность:**
  - Быстрое и безопасное VPN соединение
  - Простая настройка
  - Высокая производительность
  - Поддержка мобильных устройств
- **Технические требования:**
  - Сервер с Linux (рекомендуется) или Windows
  - Клиенты для Windows, macOS, Linux, iOS, Android
- **Стоимость:** Бесплатно
- **Приоритет внедрения:** Высокий (Фаза 2)
- **Альтернативы:** OpenVPN (бесплатно, но медленнее), коммерческие VPN решения (Cisco AnyConnect, Palo Alto GlobalProtect)

#### OpenVPN (альтернатива WireGuard)
- **Тип:** Программное обеспечение (открытое, коммерческая поддержка опциональна)
- **Назначение:** VPN для удалённого доступа
- **Функциональность:**
  - Кроссплатформенное VPN решение
  - Поддержка различных протоколов
  - Интеграция с Active Directory
- **Технические требования:**
  - Сервер с Linux или Windows
  - Клиенты для всех платформ
- **Стоимость:** 
  - Community Edition: Бесплатно
  - Access Server: от $15/подключение/год (для коммерческого использования)
- **Приоритет внедрения:** Высокий (Фаза 2) - если WireGuard не подходит
- **Альтернативы:** WireGuard (рекомендуется)

### 2.3. API Gateway

#### Kong API Gateway
- **Тип:** Программное обеспечение (открытое, коммерческая версия опциональна)
- **Назначение:** Единая точка входа для всех API с обеспечением безопасности
- **Функциональность:**
  - Маршрутизация API-запросов
  - Аутентификация и авторизация (OAuth 2.0, JWT)
  - Rate limiting
  - Логирование и мониторинг
  - Плагины для расширения функциональности
- **Технические требования:**
  - Сервер с Linux или Docker/Kubernetes
  - PostgreSQL или Cassandra для хранения конфигурации
- **Стоимость:**
  - Open Source: Бесплатно
  - Enterprise: от $2,500/месяц (при необходимости поддержки и дополнительных функций)
- **Приоритет внедрения:** Высокий (Фаза 2)
- **Альтернативы:** Apache APISIX (бесплатно), AWS API Gateway, Azure API Management (облачные платные)

#### Apache APISIX (альтернатива Kong)
- **Тип:** Программное обеспечение (открытое)
- **Назначение:** API Gateway с высокой производительностью
- **Функциональность:**
  - Аналогична Kong
  - Высокая производительность
  - Поддержка плагинов
- **Технические требования:**
  - Сервер с Linux или Kubernetes
- **Стоимость:** Бесплатно
- **Приоритет внедрения:** Высокий (Фаза 2) - альтернатива Kong
- **Альтернативы:** Kong

### 2.4. Системы аутентификации

#### Keycloak
- **Тип:** Программное обеспечение (открытое)
- **Назначение:** Управление идентификацией и доступом (IAM)
- **Функциональность:**
  - Единый вход (SSO)
  - OAuth 2.0 / OpenID Connect
  - Выдача JWT токенов
  - Управление пользователями и ролями
  - Интеграция с Active Directory
  - Многофакторная аутентификация (MFA)
- **Технические требования:**
  - Сервер с Java 11+
  - База данных (PostgreSQL, MySQL)
- **Стоимость:** Бесплатно
- **Приоритет внедрения:** Высокий (Фаза 2)
- **Альтернативы:** Okta, Auth0 (платные облачные), Microsoft Azure AD (платное)

## Категория 3: Автоматизированный контроль и мониторинг

### 3.1. DLP-системы (Data Loss Prevention)

#### Microsoft Purview Data Loss Prevention
- **Тип:** Программное обеспечение (коммерческое, облачное)
- **Назначение:** Предотвращение утечек данных
- **Функциональность:**
  - Мониторинг и блокировка передачи конфиденциальных данных
  - Защита почты, файлов, облачных хранилищ
  - Автоматическое распознавание типов данных
  - Политики защиты
- **Технические требования:**
  - Microsoft 365 подписка
  - Интеграция с Exchange, SharePoint, OneDrive
- **Стоимость:** От $12/пользователь/месяц (в составе Microsoft 365 E5)
- **Приоритет внедрения:** Высокий (Фаза 2)
- **Альтернативы:** Symantec DLP, Forcepoint DLP, собственное решение

#### Symantec DLP (Broadcom)
- **Тип:** Программное обеспечение (коммерческое)
- **Назначение:** Комплексная защита от утечек данных
- **Функциональность:**
  - Защита всех каналов утечки (почта, веб, файлы, принтеры, USB)
  - Контентный и контекстный анализ
  - Интеграция с SIEM
- **Технические требования:**
  - Серверы для компонентов DLP
  - Агенты на рабочих станциях
- **Стоимость:** От $50,000/год (зависит от количества пользователей)
- **Приоритет внедрения:** Средний (Фаза 3) - для более крупной компании
- **Альтернативы:** Microsoft Purview DLP, Forcepoint DLP

#### Forcepoint DLP
- **Тип:** Программное обеспечение (коммерческое)
- **Назначение:** Предотвращение утечек данных
- **Функциональность:**
  - Аналогична Symantec DLP
  - Простота настройки
  - Хорошая производительность
- **Технические требования:**
  - Серверы для компонентов
  - Агенты на рабочих станциях
- **Стоимость:** От $30,000/год (зависит от конфигурации)
- **Приоритет внедрения:** Средний (Фаза 3)
- **Альтернативы:** Microsoft Purview DLP, Symantec DLP

### 3.2. Системы мониторинга и логирования

#### ELK Stack (Elasticsearch, Logstash, Kibana)
- **Тип:** Программное обеспечение (открытое, коммерческая поддержка опциональна)
- **Назначение:** Централизованное логирование и анализ логов
- **Функциональность:**
  - Сбор логов из всех систем
  - Хранение и индексация логов
  - Поиск и анализ логов
  - Визуализация в дашбордах
  - Обнаружение аномалий (с Elastic Machine Learning)
- **Технические требования:**
  - Серверы с минимум 16 GB RAM для Elasticsearch
  - Дисковое пространство для хранения логов
- **Стоимость:**
  - Open Source: Бесплатно
  - Elastic Cloud: от $95/месяц (облачная версия)
  - Enterprise Support: от $95/узел/год
- **Приоритет внедрения:** Критический (Фаза 1)
- **Альтернативы:** Splunk (платное), Graylog (бесплатно), Loki (бесплатно)

#### Prometheus + Grafana
- **Тип:** Программное обеспечение (открытое)
- **Назначение:** Мониторинг метрик и визуализация
- **Функциональность:**
  - Сбор метрик из систем
  - Хранение временных рядов
  - Визуализация в дашбордах
  - Алертинг при превышении порогов
- **Технические требования:**
  - Сервер для Prometheus
  - Сервер для Grafana
  - Экспортеры метрик для мониторируемых систем
- **Стоимость:** Бесплатно
- **Приоритет внедрения:** Высокий (Фаза 2) - уже частично используется (Victoria Metrics)
- **Альтернативы:** Victoria Metrics (уже в стеке компании), Datadog (платное облачное)

#### Victoria Metrics (уже в стеке компании)
- **Тип:** Программное обеспечение (открытое)
- **Назначение:** Хранение метрик (альтернатива Prometheus)
- **Функциональность:**
  - Высокопроизводительное хранение метрик
  - Совместимость с Prometheus API
  - Меньше потребление ресурсов, чем Prometheus
- **Технические требования:**
  - Сервер для Victoria Metrics
- **Стоимость:** Бесплатно
- **Приоритет внедрения:** Уже используется
- **Примечание:** Можно использовать вместо Prometheus для хранения метрик

### 3.3. SIEM-системы (Security Information and Event Management)

#### Splunk Enterprise Security
- **Тип:** Программное обеспечение (коммерческое)
- **Назначение:** Комплексный анализ безопасности и управление инцидентами
- **Функциональность:**
  - Сбор и анализ данных безопасности
  - Корреляция событий
  - Обнаружение угроз
  - Управление инцидентами
  - Machine Learning для обнаружения аномалий
- **Технические требования:**
  - Серверы для Splunk
  - Значительные ресурсы (CPU, RAM, диск)
- **Стоимость:** От $150/GB данных/год (очень дорого для больших объёмов)
- **Приоритет внедрения:** Низкий (для будущего, если потребуется)
- **Альтернативы:** ELK Stack с Security модулями, QRadar, ArcSight

#### ELK Stack с Security модулями (альтернатива SIEM)
- **Тип:** Программное обеспечение (открытое)
- **Назначение:** Базовая SIEM функциональность на базе ELK
- **Функциональность:**
  - Сбор данных безопасности
  - Анализ и корреляция событий
  - Обнаружение аномалий через ML
  - Дашборды для безопасности
- **Технические требования:**
  - ELK Stack
  - Дополнительные модули (Elastic Security, Beats)
- **Стоимость:** Бесплатно (или Elastic Cloud от $95/месяц)
- **Приоритет внедрения:** Средний (Фаза 3) - как альтернатива коммерческим SIEM
- **Альтернативы:** Splunk, QRadar

### 3.4. Системы аудита баз данных

#### pgAudit (PostgreSQL Audit Extension)
- **Тип:** Расширение PostgreSQL (открытое)
- **Назначение:** Детальный аудит операций с базой данных
- **Функциональность:**
  - Логирование всех SQL-операций
  - Настройка уровней аудита
  - Интеграция с системой логирования
- **Технические требования:**
  - PostgreSQL с расширением pgAudit
- **Стоимость:** Бесплатно
- **Приоритет внедрения:** Критический (Фаза 1)
- **Альтернативы:** Собственное логирование на уровне приложения

## Категория 4: Управление доступом и авторизация

### 4.1. Системы управления доступом

#### Active Directory (уже используется)
- **Тип:** Программное обеспечение (коммерческое, уже установлено)
- **Назначение:** Централизованное управление пользователями и доступом
- **Функциональность:**
  - Управление учётными записями
  - Групповые политики
  - Аутентификация
- **Технические требования:**
  - Windows Server с Active Directory
- **Стоимость:** Уже установлено
- **Приоритет внедрения:** Уже используется, требуется усиление безопасности (MFA)

#### Apache Ranger
- **Тип:** Программное обеспечение (открытое)
- **Назначение:** Управление политиками безопасности для больших данных
- **Функциональность:**
  - Централизованное управление политиками доступа
  - Контроль доступа к данным в Data Lake
  - Аудит доступа
- **Технические требования:**
  - Интеграция с Hadoop, Hive, Kafka (для Data Lake)
- **Стоимость:** Бесплатно
- **Приоритет внедрения:** Средний (Фаза 3) - для Data Lake
- **Альтернативы:** OPA (Open Policy Agent)

#### OPA (Open Policy Agent)
- **Тип:** Программное обеспечение (открытое)
- **Назначение:** Универсальный движок политик для контроля доступа
- **Функциональность:**
  - Определение политик доступа в декларативном виде
  - Интеграция с различными системами
  - Проверка политик в реальном времени
- **Технические требования:**
  - Интеграция с приложениями через API
- **Стоимость:** Бесплатно
- **Приоритет внедрения:** Средний (Фаза 3)
- **Альтернативы:** Apache Ranger, собственные правила в приложениях

### 4.2. Многофакторная аутентификация (MFA)

#### Duo Security
- **Тип:** Сервис (коммерческий, облачный)
- **Назначение:** Многофакторная аутентификация
- **Функциональность:**
  - Push-уведомления на мобильные устройства
  - SMS и телефонные звонки
  - Аппаратные токены
  - Интеграция с Active Directory, VPN, приложениями
- **Технические требования:**
  - Интеграция с системами через API или агенты
- **Стоимость:** От $3/пользователь/месяц
- **Приоритет внедрения:** Высокий (Фаза 2)
- **Альтернативы:** Microsoft Authenticator (бесплатно, но требует Azure AD), Google Authenticator (бесплатно, но менее функционально)

#### Microsoft Authenticator
- **Тип:** Приложение (бесплатное, но требует Azure AD)
- **Назначение:** Многофакторная аутентификация через мобильное приложение
- **Функциональность:**
  - Push-уведомления
  - Коды для входа
  - Интеграция с Microsoft экосистемой
- **Технические требования:**
  - Azure AD (платное)
- **Стоимость:** Бесплатно (но Azure AD платное)
- **Приоритет внедрения:** Средний (если используется Azure)
- **Альтернативы:** Duo Security, Google Authenticator

## Категория 5: Управление метаданными и тегирование

### 5.1. Системы управления метаданными

#### Apache Atlas
- **Тип:** Программное обеспечение (открытое)
- **Назначение:** Управление метаданными и тегирование данных
- **Функциональность:**
  - Тегирование данных
  - Управление метаданными
  - Data Lineage (отслеживание происхождения данных)
  - Интеграция с Hadoop, Hive, Kafka
- **Технические требования:**
  - Интеграция с Data Lake и аналитическими системами
- **Стоимость:** Бесплатно
- **Приоритет внедрения:** Средний (Фаза 3) - для Data Lake
- **Альтернативы:** Collibra, Microsoft Purview (платные)

#### Microsoft Purview (для управления данными)
- **Тип:** Сервис (коммерческий, облачный)
- **Назначение:** Управление данными, метаданными и compliance
- **Функциональность:**
  - Автоматическое сканирование и классификация данных
  - Управление метаданными
  - Data Lineage
  - Compliance checking
- **Технические требования:**
  - Azure подписка
- **Стоимость:** От $0.50/GB данных/месяц
- **Приоритет внедрения:** Средний (Фаза 3) - если используется Azure
- **Альтернативы:** Apache Atlas (бесплатно), Collibra (платное)

## Категория 6: Аппаратное обеспечение

### 6.1. Серверы

#### Серверы для баз данных
- **Тип:** Аппаратное обеспечение
- **Назначение:** Хостинг баз данных PostgreSQL, ClickHouse
- **Технические требования:**
  - Минимум 16 CPU cores, 64 GB RAM
  - SSD диски (минимум 2 TB)
  - TPM 2.0 для защиты ключей
  - RAID для отказоустойчивости
- **Стоимость:** От $5,000 до $15,000 (зависит от конфигурации)
- **Приоритет внедрения:** Критический (Фаза 1) - если требуется новая инфраструктура
- **Производители:** Dell, HP, Supermicro

#### Серверы для приложений
- **Тип:** Аппаратное обеспечение
- **Назначение:** Хостинг веб-приложений, API, микросервисов
- **Технические требования:**
  - Минимум 8 CPU cores, 32 GB RAM
  - SSD диски
  - TPM 2.0
- **Стоимость:** От $3,000 до $10,000
- **Приоритет внедрения:** Критический (Фаза 1)
- **Производители:** Dell, HP, Supermicro

#### Серверы для мониторинга и логирования
- **Тип:** Аппаратное обеспечение
- **Назначение:** ELK Stack, Prometheus, системы мониторинга
- **Технические требования:**
  - Минимум 16 CPU cores, 64 GB RAM
  - Большой объём дискового пространства (10+ TB для логов)
  - Быстрые диски (SSD для индексов, HDD для хранения)
- **Стоимость:** От $5,000 до $20,000 (зависит от объёма логов)
- **Приоритет внедрения:** Высокий (Фаза 2)
- **Производители:** Dell, HP, Supermicro

### 6.2. Сетевое оборудование

#### Firewall (межсетевой экран)
- **Тип:** Аппаратное обеспечение или программное
- **Назначение:** Контроль сетевого трафика, защита от атак
- **Функциональность:**
  - Фильтрация трафика
  - Защита от DDoS
  - VPN функциональность (опционально)
  - Инспекция SSL/TLS трафика
- **Технические требования:**
  - Пропускная способность согласно нагрузке
  - Поддержка VPN (если используется)
- **Стоимость:** От $2,000 до $20,000 (зависит от модели)
- **Приоритет внедрения:** Критический (Фаза 1) - если не установлен
- **Производители:** pfSense (бесплатное ПО), Fortinet, Palo Alto, Cisco

#### Сетевые коммутаторы
- **Тип:** Аппаратное обеспечение
- **Назначение:** Коммутация сетевого трафика
- **Технические требования:**
  - Управляемые коммутаторы
  - Поддержка VLAN для сегментации сети
- **Стоимость:** От $500 до $5,000 (зависит от модели)
- **Приоритет внедрения:** Высокий (Фаза 2) - для сегментации сети
- **Производители:** Cisco, HP, Ubiquiti

## Выводы

Реестр включает как бесплатные открытые решения, так и коммерческие продукты. Рекомендуется начать с бесплатных решений для базовой защиты (Фаза 1), а затем постепенно внедрять коммерческие решения там, где они дают значительные преимущества (Фаза 2-3).

Большинство критически важных средств защиты доступны бесплатно (PostgreSQL, HashiCorp Vault, ELK Stack, WireGuard), что позволяет начать внедрение с минимальными затратами.

Коммерческие решения (DLP, MFA, SIEM) можно внедрять по мере роста компании и увеличения требований к безопасности.
