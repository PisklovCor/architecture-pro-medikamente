# Cutover-план миграции

## Введение

Данный документ содержит детальный cutover-план миграции компании "Медикаменте" с монолитной системы на микросервисную архитектуру с использованием подхода Branch by abstraction. План разбит на этапы с описанием действий, задач, ответственных, сроков и мер по управлению рисками.

## Общая структура миграции

Миграция разбита на 6 основных фаз:

1. **Подготовка и инфраструктура** (1-2 месяца)
2. **Миграция данных** (2-3 месяца)
3. **Новые сервисы** (3-4 месяца)
4. **Интеграции** (2-3 месяца)
5. **Клиентские порталы** (2-3 месяца)
6. **Аналитика и оптимизация** (2-3 месяца)

**Общий срок миграции:** 12-18 месяцев

## План отката

### Общие принципы отката

1. **Откат по этапам** - каждый этап миграции должен иметь возможность отката
2. **Сохранение старых систем** - старые системы продолжают работать до полного завершения миграции
3. **Резервное копирование** - перед каждым этапом создаются резервные копии
4. **Тестирование отката** - регулярное тестирование процедур отката

### Процедуры отката по фазам

**Фаза 1 (Инфраструктура):**
- Откат: Возврат к использованию старого сервера
- Время отката: 1-2 часа
- Ответственный: Администратор сети

**Фаза 2 (Данные):**
- Откат: Возврат к использованию старых источников данных
- Время отката: 2-4 часа
- Ответственный: Технический директор

**Фаза 3-6 (Сервисы):**
- Откат: Отключение новых сервисов, возврат к старым процессам
- Время отката: 4-8 часов
- Ответственный: Технический директор, Администратор сети

### Критерии принятия решения об откате

1. **Критические ошибки** - ошибки, приводящие к потере данных или невозможности работы
2. **Проблемы с безопасностью** - обнаружение уязвимостей безопасности
3. **Проблемы с производительностью** - система не справляется с нагрузкой
4. **Несоответствие требованиям** - система не соответствует бизнес-требованиям

### Процесс отката

1. **Обнаружение проблемы** - выявление критической проблемы
2. **Оценка ситуации** - оценка серьёзности проблемы и возможности исправления
3. **Принятие решения** - решение об откате принимается техническим директором и руководством
4. **Уведомление** - уведомление всех заинтересованных сторон
5. **Выполнение отката** - выполнение процедуры отката
6. **Проверка** - проверка работоспособности после отката
7. **Анализ** - анализ причин проблемы и планирование исправления
